# WART Miner: From Zero / 穷小子的 WART 矿场

A bilingual mining management browser game. All cash, WART and performance figures are simulated. Not affiliated with the Warthog project. No real mining or wallet connection.

从一台旧电脑起步的中英双语小游戏。现金、WART、算力均为游戏数值。

## Local play

Open docs/index.html (Chinese) or docs/en.html (English). No dependencies. Saves stay in your browser.

## GitHub Pages setup

Repository Settings → Pages → Deploy from a branch → main → /docs → Save.

Expected addresses after successful deployment (not yet published):

- Chinese: https://athundera.github.io/wart-miner/
- English: https://athundera.github.io/wart-miner/en.html

## Gameplay

Take jobs, buy secondhand CPUs and GPUs, balance power, manage temperature and bills, sell simulated WART, and upgrade to dedicated dual-engine rigs.
